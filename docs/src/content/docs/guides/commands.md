## CLI commands

| Command | Description |
| --- | --- |
| `evalkit init <project-name>` | Initialize a new evaluation project |
| `evalkit check` | Check system prerequisites |

## Assistant commands

Available inside your AI assistant after `evalkit init`.

| Command | Description |
| --- | --- |
| `/evalkit.quick` | Step-by-step evaluation guide |
| `/evalkit.plan` | Analyze the agent and design an evaluation strategy |
| `/evalkit.data` | Generate test cases for evaluation |
| `/evalkit.trace` | Add tracing to your agent |
| `/evalkit.run_agent` | Run the agent and collect traces |
| `/evalkit.eval` | Write and execute evaluation code over traces |
| `/evalkit.report` | Analyze results and recommend improvements |
